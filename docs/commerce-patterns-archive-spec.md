# Indizio Commerce Patterns — Archived Product Concept

**Status:** Parked and removed from the live website  
**Last updated:** August 22, 2026

## 1. Why this document exists

Commerce Patterns was planned as a library of repeatable ecommerce interface and conversion patterns, including buy boxes, cart drawers, cancellation flows, and other recurring storefront decisions. It has been removed from the current live product to keep Indizio focused, but the concept is preserved here in case it is reintroduced later.

## 2. Original purpose

Help users study a specific interface or journey pattern across multiple brands without navigating the full Website Library one brand at a time.

Examples:

- Buy boxes
- Product galleries
- Variant selectors
- Cart drawers
- Shipping thresholds
- Subscription selectors
- Review modules
- Navigation and search
- Checkout-adjacent trust cues
- Cancellation and retention flows

## 3. Potential data model

### Pattern

- Name and slug
- Category
- Description
- User problem addressed
- Editorial analysis
- Related examples
- Related Fieldnotes and Ecommerce Ideas
- Publication status

### Pattern example

- Parent pattern
- Website
- Exact page URL
- Screenshot or crop
- Annotation
- Industry
- Date observed
- Visibility status

## 4. Potential experience

- Pattern index grouped by customer journey or storefront surface
- Dedicated pattern pages with multiple annotated examples
- Industry and platform filters
- Links to the source website and relevant Brand Atlas page
- Saving patterns or individual examples into private research collections

## 5. Conditions for bringing it back

Reconsider Commerce Patterns only when:

- The Website Library contains enough classified examples.
- Exact pages or screenshots can be captured efficiently.
- Brand Atlas provides stable page-level records.
- Indizio has enough editorial capacity to explain patterns rather than merely display screenshots.
- The module has a clear distinction from CRO Fieldnotes and Ecommerce Ideas.

## 6. Why it is parked

- It expands taxonomy and moderation work substantially.
- It depends on page-level evidence and screenshot tooling that are not mature yet.
- Similar material can initially be published through CRO Fieldnotes and Ecommerce Ideas.
- Removing it makes the current product navigation and positioning clearer.

## 7. Reintroduction sequence

1. Define the smallest useful pattern taxonomy.
2. Pilot 3–5 high-value patterns.
3. Source examples from approved library websites and Brand Atlas pages.
4. Add editorial annotations and permission/removal workflows.
5. Validate demand before restoring it to primary navigation.
